# AIBINU Flexiprep Student Management — Phase 2

Approved student schema: Student ID, First Name, Last Name, Full Name, Gender, Date of Birth, Phone, Email, Address, Nationality, Religion, State of Origin, LGA of Origin, Parent/Guardian, Parent Phone, Class, Programme, Status, Registration Date, Photo.

Student IDs use `AF-YYYY-NNNN` and are generated automatically. This build uses local demo data; Airtable synchronization is the next integration step.
